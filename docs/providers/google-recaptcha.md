# Configure Google reCAPTCHA

The complete Google reCAPTCHA dashboard and plugin configuration guide is in
preparation.

WP Captcha Shield implements:

- score-based mode;
- checkbox mode;
- invisible mode;
- server-side assessments through the Google Cloud Fraud Defense reCAPTCHA
  Enterprise assessment API.

This page will document:

1. Google Cloud project setup;
2. reCAPTCHA Enterprise key creation;
3. API enablement and credential creation;
4. project ID, API key, and site key configuration;
5. mode and minimum-score selection;
6. local and production testing;
7. troubleshooting.
